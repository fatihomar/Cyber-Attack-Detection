# Cyber Attack Detection

## Project Overview
This project aims to detect cyber attacks by classifying network traffic into Normal and Attack categories using Data Mining and Machine Learning classification algorithms.

## Dataset
UNSW-NB15 Network Intrusion Detection Dataset.

## Project Objectives
- Analyze and understand the dataset.
- Investigate data quality, missing values, and duplicate records.
- Perform data preprocessing and feature analysis.
- Train different classification algorithms.
- Evaluate and compare model performance.

## Planned Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors (KNN)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Project Status
Currently in the dataset inspection and analysis phase.
